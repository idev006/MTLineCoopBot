# บทที่ 1 บทนำ (Introduction)

## 1.1 หลักการและเหตุผล (Rationale)

สหกรณ์เป็นองค์กรที่ให้บริการด้านการเงินและสวัสดิการแก่สมาชิก โดยมีกิจกรรมที่ต้องติดต่อสื่อสารกับสมาชิกเป็นจำนวนมาก เช่น การประชาสัมพันธ์ข่าวสาร การแจ้งประกาศ การให้ข้อมูลยอดเงินฝาก เงินกู้ เงินปันผล การยื่นคำขอกู้ การดาวน์โหลดเอกสารและแบบฟอร์ม ตลอดจนการติดต่อเจ้าหน้าที่

ในปัจจุบัน สมาชิกส่วนใหญ่ใช้งานแอปพลิเคชัน LINE เป็นช่องทางสื่อสารหลัก เนื่องจากใช้งานง่าย เข้าถึงได้ทุกที่ทุกเวลา และไม่ต้องติดตั้งแอปพลิเคชันเพิ่มเติม การพัฒนาระบบ LINE Bot จึงเป็นแนวทางที่เหมาะสมในการยกระดับการให้บริการของสหกรณ์ให้ทันสมัย ลดภาระงานของเจ้าหน้าที่ ลดค่าใช้จ่ายในการติดต่อสื่อสาร และเพิ่มความพึงพอใจให้แก่สมาชิก

โครงการ **MTLineCoopBot** จึงเกิดขึ้นเพื่อพัฒนาระบบ LINE Official Account ที่ให้บริการสมาชิกแบบเบ็ดเสร็จผ่านช่องทางเดียว ครอบคลุมทั้งเมนูการให้บริการ การลงทะเบียนสมาชิก และเครื่องมือคำนวณทางการเงิน

## 1.2 วัตถุประสงค์ของโครงการ (Objectives)

1. เพื่อพัฒนาระบบ LINE Bot สำหรับให้บริการข้อมูลและสวัสดิการแก่สมาชิกสหกรณ์ผ่านช่องทาง LINE
2. เพื่อออกแบบและใช้งาน Rich Menu จำนวน 5 แท็บ ให้สมาชิกเข้าถึงบริการหลักได้ภายในไม่กี่คลิก
3. เพื่อให้สมาชิกสามารถลงทะเบียนผูกบัญชี LINE กับบัญชีสมาชิก (Member Activation) ได้ด้วยตนเองผ่านรหัส Activate
4. เพื่อให้สมาชิกสามารถคำนวณยอดเงินผ่อนชำระสินเชื่อด้วยเครื่องคำนวณออนไลน์ที่ถูกต้องตามมาตรฐานการเงิน (Actual/365)
5. เพื่อสร้างระบบที่มีโครงสร้างโค้ดชัดเจน ดูแลรักษาง่าย และพร้อมต่อการขยายฟีเจอร์ในอนาคต

## 1.3 ขอบเขตของโครงการ (Scope)

### 1.3.1 ขอบเขตงานที่ทำ (In-Scope)

- พัฒนา Webhook endpoint (Google Apps Script Web App) สำหรับรับ event จาก LINE
- ออกแบบและ Deploy Rich Menu 5 แท็บ พร้อม Alias สำหรับสลับแท็บ
  - แท็บ 1: ข้อมูลส่วนตัว
  - แท็บ 2: เงินกู้ & สวัสดิการ
  - แท็บ 3: ข่าวสารสหกรณ์
  - แท็บ 4: เอกสาร & คู่มือ
  - แท็บ 5: ติดต่อเรา
- พัฒนาการตอบกลับด้วย Flex Message เมื่อสมาชิกคลิกเมนูต่าง ๆ
- พัฒนาระบบ Activate สมาชิกผ่านคำสั่ง `activate:{{CODE}}` โดยผูก `line_user_id` กับข้อมูลสมาชิกใน Google Sheets
- พัฒนาโครงสร้างข้อมูลกลาง (DataDict) เป็น Single Source of Truth สำหรับตาราง `t_member_mast`
- พัฒนาเครื่องคำนวณสินเชื่อออนไลน์ (Web Application) รองรับการคำนวณดอกเบี้ยแบบวันจริง (Actual/365)

### 1.3.2 ขอบเขตงานที่อยู่นอกโครงการ (Out-of-Scope)

- การเชื่อมต่อกับระบบบัญชี/ระบบงานหลักของสหกรณ์โดยตรง (Backend Core Banking)
- การชำระเงินผ่าน LINE Pay หรือช่องทางอิเล็กทรอนิกส์อื่น
- การออกแบบภาพกราฟิกต้นแบบ (Graphic Design) ของ Rich Menu — โครงการนี้ใช้ภาพสำเร็จรูปที่อัปโหลดไว้ใน Google Drive
- แอปพลิเคชันมือถือหรือเว็บไซต์หลักของสหกรณ์

## 1.4 ประโยชน์ที่คาดว่าจะได้รับ (Expected Benefits)

| ผู้ที่เกี่ยวข้อง | ประโยชน์ที่ได้รับ |
|----------------|------------------|
| สมาชิก | เข้าถึงบริการสหกรณ์ได้ตลอด 24 ชั่วโมงผ่าน LINE ที่ใช้งานอยู่แล้ว ได้ข้อมูลรวดเร็ว ไม่ต้องเดินทางหรือโทรสอบถาม |
| เจ้าหน้าที่สหกรณ์ | ลดภาระงานตอบคำถามซ้ำซ้อน ลดงานเอกสาร ใช้เวลากับงานที่มีมูลค่าสูงขึ้น |
| ผู้บริหารสหกรณ์ | เพิ่มช่องทางการประชาสัมพันธ์ ภาพลักษณ์ทันสมัย เพิ่มความพึงพอใจและความผูกพันของสมาชิก |
| ทีมพัฒนา | ได้สถาปัตยกรรมและโครงสร้างโค้ดที่เป็นมาตรฐาน ขยายต่อได้ง่าย |

## 1.5 นิยามศัพท์เฉพาะ (Glossary)

| คำศัพท์ | ความหมาย |
|--------|----------|
| LINE Bot | บัญชี LINE ที่ทำงานอัตโนมัติ ตอบสนองต่อข้อความหรือการกระทำของผู้ใช้ |
| Rich Menu | เมนูภาพที่แสดงในหน้าจอแชท LINE ประกอบด้วยพื้นที่คลิก (Area) ที่ผูกกับ Action ต่าง ๆ |
| Alias | ชื่อแทน (Rich Menu Alias) ที่ใช้สลับแท็บ Rich Menu ผ่าน Action แบบ `richmenuswitch` |
| Postback | Event ที่ LINE ส่งมาเมื่อผู้ใช้คลิกปุ่ม/พื้นที่ที่มี Action ประเภท postback |
| Webhook | URL ที่ LINE ใช้ส่ง event มายังระบบเมื่อมีเหตุการณ์เกิดขึ้น |
| Flex Message | รูปแบบข้อความของ LINE ที่สามารถออกแบบโครงสร้าง/สีสันได้เอง (คล้ายบัตรข้อมูล) |
| Channel Access Token | Token สำหรับยืนยันตัวตนของ Bot ในการเรียก LINE Messaging API |
| Activate | กระบวนการผูก LINE User ID เข้ากับรหัสสมาชิกผ่านรหัสลับที่กำหนดให้ |
| Actual/365 | วิธีคำนวณดอกเบี้ยโดยนับจำนวนวันจริงระหว่างงวด หารด้วย 365 วัน |
| SSOT | Single Source of Truth — แหล่งข้อมูลกลางที่เป็นความจริงเพียงหนึ่งเดียวของระบบ |
| clasp | Command Line Interface อย่างเป็นทางการของ Google Apps Script ใช้ push/pull โค้ด |

## 1.6 ข้อกำหนดทางเทคนิค (Technical Requirements)

### 1.6.1 ฮาร์ดแวร์/ซอฟต์แวร์

| รายการ | ข้อกำหนด |
|--------|----------|
| แพลตฟอร์มพัฒนา | Google Apps Script Runtime V8 (Cloud-based ไม่ต้องมีเซิร์ฟเวอร์) |
| เครื่องมือพัฒนา | clasp (npm package) หรือ Apps Script Editor บนเบราว์เซอร์ |
| บัญชีที่ต้องใช้ | Google Account, LINE Developers Console, GitHub (สำหรับ Pages) |

### 1.6.2 ข้อกำหนดด้านขีดจำกัดของแพลตฟอร์ม

- Google Apps Script มี quota การเรียกใช้ต่อวัน (Services quotas) เช่น UrlFetchApp, SpreadsheetApp
- LINE Reply API อนุญาตตอบกลับได้ครั้งเดียวต่อ `replyToken` และ `replyToken` มีอายุสั้น (ประมาณ 1 นาที)
- Rich Menu รองรับ Action ต่อเมนูได้หลายประเภท แต่ขนาดภาพและจำนวน Area มีข้อจำกัดตามข้อกำหนดของ LINE

> รายละเอียดเชิงลึกของสถาปัตยกรรมและข้อจำกัดจะกล่าวในบทที่ 2–3

## สรุปท้ายบท

บทนี้กล่าวถึงที่มา วัตถุประสงค์ ขอบเขต ประโยชน์ และนิยามศัพท์ของโครงการ ซึ่งเป็นกรอบสำหรับการศึกษาในบทถัด ๆ ไป โดยบทที่ 2 จะเป็นการวิเคราะห์ระบบในเชิงลึก ทั้งสถาปัตยกรรม กระแสการทำงาน และความเสี่ยง
